# Wealth Empire 3.0 — Financial World & Investment Simulator

لعبة Android تعمل دون اتصال. جميع الأموال والأصول افتراضية. لا إيداع أو سحب أو تداول حقيقي، ولا تعدين أو قمار. العربية هي اللغة الأساسية مع موارد إنجليزية كاملة. رأس مال المستثمر الافتراضي $20,000.

## التشغيل والبناء

افتح مجلد `WealthEmpire` في Android Studio، اختر JDK 17، وثبّت Android SDK 35. انتظر Gradle Sync ثم Run. المشروع يتضمن Gradle Wrapper 8.9؛ أول بناء يحتاج إنترنت لتنزيل الاعتماديات فقط. الحد الأدنى Android 8 / API 26.

```sh
chmod +x gradlew
./gradlew :core:test :app:testDebugUnitTest :app:assembleDebug :app:lintDebug :app:assembleDebugAndroidTest
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. حزمة التطبيق `com.wealthempire` ومفتاح التطوير `dev-signing/debug.keystore` محفوظان للتحديثات. المفتاح للاختبار الشخصي؛ عند النشر العام استخدم مفتاح إصدار خاص. التقرير `VERIFICATION.md` يحدد ما تم اختباره فعلًا.

## دورة اللعب

راقب الاقتصاد والأخبار والتقويم، حلل عوامل الأصل، انقل المال إلى محفظته، استثمر أو افتح صفقة، ثم تابع المخاطر والتطورات. أدوات التحليل والتخصصات تتقدم بالخبرة ولا تمنح أموالًا مجانية. الإعدادات توفر Pause و×1 و×5 و×12 و×16، لغة، تقليل الحركة، إشعارات خفيفة اختيارية، صوت تنفيذ اختياري، ولعبة جديدة مع تأكيد.

- **Pure Investor:** $20,000 دون دخل جانبي.
- **Real Life:** $20,000، راتب محاكى $3,200 ومصاريف $2,450، صافي $750 كل 30 يوم لعبة.
- **Hardcore:** $8,000 وصافي جانبي $100 كل 30 يوم لعبة.

الأسواق تشمل الكريبتو والأسهم المعروفة وSPY/QQQ/SOXX/SOXL/SOXS، الذهب والفضة والنفط والغاز، عملات أجنبية بوحداتها الأصلية، وسندي خزانة 2Y و10Y. الإدراجات تعرض الجودة والمعروض والتحرير والمخاطر. Earn يدخر كمية الأصل نفسه بفائدة سنوية محاكاة وخيارات مرنة ومقفلة.

## العالم والمحاكاة

اقتصادات الولايات المتحدة وأوروبا والصين واليابان، مراحل التوسع والتباطؤ والركود والتعافي، التضخم والبطالة والنمو والائتمان والسيولة والعوائد والتوقعات. التقويم يصدر CPI والوظائف والنمو وقرارات البنوك المركزية والمخزونات وأرباح الشركات؛ Actual مقابل Forecast يحدث مفاجأة تؤثر في النظام الاقتصادي. القرار النقدي يعتمد على التضخم والنمو والبطالة والأجور والائتمان.

تسلسل النظام: حدث اقتصادي/شركة/شبكة/جغرافيا سياسية → تغير عوامل العالم → تقييم الأصل والسيولة → سعر مع عدم يقين محدود → خبر عربي/إنجليزي. تتفرع قصص التجارة والتوترات والأمن والائتمان وتتطور أيامًا. الشركات لها الإيرادات والهامش والأرباح والدين والنقد والتوجيهات والقطاع؛ الكريبتو له نشاط وأمن ومعروض وسيولة؛ السلع لها عرض وطلب ومخزون وطقس وشحن؛ الفوركس يتأثر بالفروق الاقتصادية والعوائد. SOXL/SOXS يتبعان SOXX برافعة يومية مركبة وليست عائدًا ثابتًا طوال الاحتفاظ.

هذه نماذج لعب سببية ذات حدود ومعاملات معلنة في المصدر؛ ليست بيانات سوق مباشرة ولا نموذجًا اقتصاديًا معايرًا للتنبؤ بالعالم الحقيقي. أرقام الشركات والاقتصاد وأسعار البداية افتراضية، حتى مع استخدام أسماء شركات معروفة.

## التداول والحفظ والأداء

- المالية: `BigDecimal`، كمية الأصل × فرق السعر لحساب P&L، Maker 0.02% وTaker 0.05%، عمق/Spread/Slippage وتمويل كل 8 ساعات لعبة. Cross يستخدم حقوق المحفظة الصافية والتحوط؛ Isolated يقيد الخسارة بهامش الصفقة. إغلاق جزئي وإدارة TP/SL وأوامر Market/Limit/Stop.
- الأوامر: Actor يمتلك حالة العالم، وطابور اللاعب يُفرغ قبل كل خطوة محاكاة محدودة. العمل على Dispatchers.Default؛ كتابة سجل صغير على IO قبل تأكيد الأمر. ضغط Snapshot منفصل على IO ولا يقفل أوامر التداول.
- الحفظ: Room v3 مع Event Journal مرتب ومتحقق بـSHA-256، يحتفظ بالنتائج المالية المنفذة دون إعادة تسعير الأمر عند الاستعادة. Snapshot مضغوط بأسلوب streaming كل 30 ثانية وعند الخلفية، مقسم إلى 256KiB مع نسخة احتياطية. حاجز جيل/مراجعة يمنع حفظًا قديمًا من استبدال لعبة جديدة. DataStore للإعدادات.
- الغياب: لا تُحذف الساعات المنقضية. المحاكاة قصيرة الخطوات للغياب القصير، ثم دقائق/ساعات/6 ساعات حسب المدة والتعرض. تنقسم عند الخبر والتمويل والجلسة والإدراج واليوم. الأوامر والحماية تمر عبر نقاط مسار السعر؛ تقرير العودة يوضح التغيرات والتنفيذات.
- الزمن: سرعة اللعبة لا تغير زمن الرسوم أو الاستجابة؛ دقيقة اللعبة عند ×1 = 60 ثانية حقيقية. Pause يوقف العالم بما فيه فترة الغياب. تغيير السرعة يسوي المدة السابقة بسرعتها القديمة. Skip to Event يحذر بشأن التعرض المفتوح.
- الواجهات: Hub للأسواق، Terminal بتبويبات، بطاقة صفقة مختصرة، محفظة وتوزيع ومخاطر، اقتصاد وتقويم، تقدم وتخصصات وبحوث، أخبار وإدراجات وEarn. رسم الشموع يترك السحب العمودي للصفحة، والسحب الأفقي/إصبعين للشارت. حساب حدود التصفية للعرض خارج الخيط الرئيسي.

## حدود يجب معرفتها

المحاكاة المتكيفة أثناء الغياب تستخدم مسارات عينات، ولا تعيد كل حركة سوق مفقودة أو كل شمعة دقيقة؛ لذا لا تتطابق نتائج الغياب الطويل حسابيًا مع تشغيل كل Tick. أولوية العبور على المسار المتصل تختلف عن فجوة سعرية؛ الفجوة قد تؤدي للتصفية أولًا. حدود Cross تفترض ثبات أسعار الأصول الأخرى لحظة التقدير ويمكن أن توجد حدود علوية وسفلية للتحوط.

جلسة الأسهم محاكاة UTC من الاثنين للجمعة 09:30–16:00 دون عطلات بورصات أو توقيت صيفي. الفوركس والسلع والسندات تتوقف في نهاية الأسبوع. سندات البداية بسعر وحدة $100 وكوبون ثابت محاكى محسوب حسب مدة الاحتفاظ، مع سعر يتأثر بالعائد؛ لا مزادات أو استحقاق حقيقي حاليًا. منحنى العوائد نقطتان فقط. شارات الأصول مرسومة محليًا وليست حزمة شعارات تجارية رسمية.

التحقق الآلي لا يساوي ضمان 150ms على كل هاتف. راجع التقرير لبيئة قياس الاستجابة وما لم يُشغل على جهاز. تطبيق Android الفعلي هو الناتج؛ لم يُنشأ تطبيق ويب بديل.

## التطوير اللاحق

| المسار | المسؤولية |
|---|---|
| `core/world` | حالة العالم المتسلسلة ونسخها |
| `core/economy` | الدورة الاقتصادية والسياسة النقدية |
| `core/events` | التقويم والأحداث والقصص والخبر الناتج |
| `core/market` | الأصول والسعر والسيولة والشموع والزمن والإدراجات |
| `core/trading`, `wallet`, `savings` | التنفيذ والمالية والضمانات وEarn |
| `core/portfolio`, `progression`, `statistics` | المخاطر والخبرة والرتب والتحديات |
| `app/repository`, `data` | Actor وRoom والسجل وSnapshot وDataStore |
| `app/ui`, `navigation` | Compose وMVVM والهوية والواجهات |

ابدأ التعديلات القادمة من هذا ZIP، لا تنشئ مشروعًا جديدًا. حافظ على الهوية والمفتاح، زد versionCode، وأضف migrations عند تغيير المخطط. المخطط 6 يحافظ على أرصدة مخطط 5؛ الأقدم 1–4 يعاد مرة واحدة لأن المستخدم وافق على تجاهل الاقتصاد القديم. اختبارات JVM وAndroid instrumentation والمخططات موجودة داخل المشروع. العقار والأعمال والقروض والخيارات وإحصاءات متعددة اللاعبين محفوظة لتوسعة لاحقة.
